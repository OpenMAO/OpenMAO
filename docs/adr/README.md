# Architecture Decision Records

Accepted decisions that shape OpenMAO's contracts, governance, and architecture. Each ADR states
its context, the decision, the consequences, and the alternatives rejected — so a change of course
later is a recorded reversal, not a silent drift.

## Numbering

ADR-0001–0012 predate this public directory. They publish here under the ADR-0006 hygiene pass
(public-or-dead governance records: restore the historical records, redact third-party material
that lacks consent, keep numbering continuous). Until that pass lands, the numbering gap is
deliberate, not an error.
